# EncTool

Code Encrypter — encrypt/decrypt file bash dan encrypt python dalam format Marshal.

> Original oleh [Cheos969](https://raw.githubusercontent.com/CHS969/CheosEnc). MIT License.
> Versi ini sudah diperbaiki untuk Termux / Python 3.

## Fitur

- 🔒 Encrypt file Bash (via `bash-obfuscate`)
- 🔓 Decrypt file Bash
- 🔐 Encrypt file Python (Marshal)

## Prasyarat

- Termux / Linux
- Node.js (`pkg install nodejs`)
- Python 3 (`pkg install python`)
- `bash-obfuscate` (dipasang otomatis oleh installer)
